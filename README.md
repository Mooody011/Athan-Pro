# 🕌 تطبيق آذان برو (Athan Pro)

تطبيق إسلامي شامل لمواقيت الصلاة والأذكار والقبلة والسبحة وختمة القرآن ومتابع الصلوات وحاسبة الزكاة، مبني بـ **Flutter** مع بناء تلقائي لملف الـ APK عبر **GitHub Actions**.

## 🚀 خطوات البناء على GitHub (من الموبايل أو الكمبيوتر)
1. أنشئ مستودع (Repository) جديد على GitHub.
2. فك ضغط ملف `athan_pro_github.zip` وارفع محتوياته إلى المستودع (مع التأكد من وجود مجلد `.github/workflows/build.yml`).
3. ادخل على تبويب **Actions** في المستودع.
4. ستجد عملية البناء `Build Athan Pro APK` بدأت تلقائياً (أو اضغط **Run workflow**).
5. بعد انتهاء البناء (حوالي 3–5 دقائق)، افتح المهمة وحمّل ملف **`Athan-Pro-Release-APK`** وثبّته على هاتفك الأندرويد.

## ✨ أبرز المميزات
- **مواقيت الصلاة بدقة فلكية أوفلاين 100%** مع 9 طرق حساب (الهيئة المصرية العامة للمساحة، أم القرى، رابطة العالم الإسلامي، كراتشي، ISNA، دبي، قطر، الكويت، سنغافورة) + المذهب الشافعي والحنفي + التعديل اليدوي للدقائق والتاريخ الهجري.
- **عداد تنازلي لحظي بالثانية** للصلاة القادمة مع حساب منتصف الليل والثلث الأخير من الليل.
- **أصوات الآذان والتنبيه**: نغمة تنبيه إسلامية مدمجة تعمل بدون إنترنت + خيارات استماع لمؤذنين مشهورين.
- **بوصلة القبلة الاحترافية**: تعمل بحساس البوصلة المغناطيسية مع خيار المعايرة اليدوية + الزاوية والمسافة الدقيقة إلى الكعبة المشرفة.
- **حصن المسلم (الأذكار)**: أذكار الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، الأدعية القرآنية والنبوية، والرقية الشرعية مع عداد تفاعلي واهتزاز خفيف.
- **السبحة الإلكترونية**: عداد دائري مضيء بأهداف مخصصة وإحصائيات يومية وكلية وإمكانية إضافة أذكارك الخاصة.
- **ختمة القرآن الكريم**: متابعة الـ 30 جزءاً والـ 604 صفحات + فهرس السور الـ 114 وحساب الورد اليومي.
- **أسماء الله الحسنى**: الـ 99 اسماً مع المعاني والبحث الفوري.
- **متابع الصلوات اليومية**: تتبع الفروض والسنن والوتر والضحى مع نسبة الالتزام.
- **حاسبة الزكاة**: حساب زكاة المال والذهب والفضة مع التحقق من النصاب (85 جم ذهب).
